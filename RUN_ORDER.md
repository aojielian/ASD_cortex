# Suggested run order

The scripts are organized to mirror the manuscript analysis workflow.

1. Program definition and BrainSpan developmental prioritization
2. Adult bulk program scoring and cross-cohort summaries
3. Adult single-cell/single-nucleus localization
4. Fetal developmental-state localization
5. Bulk deconvolution and composition-adjusted analyses
6. SynGO, Reactome, transcription-factor target, and matched-random analyses
7. Inter-gene-correlation-aware CAMERA/mROAST sensitivity analyses
8. Revision/final sensitivity analyses:
   - detection-filtered adult bulk rescoring
   - BrainSpan prenatal-boundary sensitivity
9. Main and supplementary figure generation

Before running, place Zenodo intermediate files in the expected locations or edit input paths in the scripts.
